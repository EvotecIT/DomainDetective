# New-DDDesiredStateDnssec
## SYNOPSIS
Creates a DNSSEC desired state policy fragment.

## SYNTAX
### __AllParameterSets
```powershell
New-DDDesiredStateDnssec [-Enabled <Boolean>] [-RequireChainValid <Boolean>] [-MinRrsigDaysRemaining <Int32>] [<CommonParameters>]
```

## DESCRIPTION
The returned object is intended to be used with New-DDDesiredState or applied to an existing configuration.

## EXAMPLES

### EXAMPLE 1
```powershell
PS> New-DDDesiredStateDnssec -RequireChainValid $true -MinRrsigDaysRemaining 7
```
