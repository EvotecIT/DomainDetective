# New-DDDesiredStateDnsHealth
## SYNOPSIS
Creates a DNS health desired state policy fragment.

## SYNTAX
### __AllParameterSets
```powershell
New-DDDesiredStateDnsHealth [-Enabled <Boolean>] [-RequireAtLeastOneResult <Boolean>] [-RequireServersResponsive <Boolean>] [-RequireSoaSerialConsistent <Boolean>] [-RequireApexAddressesConsistent <Boolean>] [<CommonParameters>]
```

## DESCRIPTION
The returned object is intended to be used with New-DDDesiredState or applied to an existing configuration.

## EXAMPLES

### EXAMPLE 1
```powershell
New-DDDesiredStateDnsHealth -Enabled $true
```
