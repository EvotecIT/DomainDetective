# Test-DDDmarcAggregate
## SYNOPSIS
Cmdlet to parse DMARC aggregate reports and summarize failures.

## SYNTAX
### __AllParameterSets
```powershell
Test-DDDmarcAggregate [-Path] <string> [-SummarizeBy <DmarcAggregateSummarizeBy>] [-Deduplicate] [-Json] [-ExportFormat <ReportFormat[]>] [-ExportPath <string>] [-OpenInBrowser] [-ExportArtifacts] [-ArtifactsDirectory <string>] [-DisableParallel] [-ThrottleLimit <int>] [-MaxParallelism <int>] [-DnsParallelism <int>] [-DnsEndpoints <DnsEndpoint[]>] [-MultiResolverStrategy <MultiResolverStrategy>] [-MultiResolverMaxParallelism <int>] [<CommonParameters>]
```

## DESCRIPTION
Cmdlet to parse DMARC aggregate reports and summarize failures.

## EXAMPLES

### EXAMPLE 1
```powershell
Test-DDDmarcAggregate -Path 'C:\Path'
```
