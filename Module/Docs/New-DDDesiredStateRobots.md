# New-DDDesiredStateRobots
## SYNOPSIS
Creates a robots.txt desired state policy fragment.

## SYNTAX
### __AllParameterSets
```powershell
New-DDDesiredStateRobots [-Enabled <bool>] [-RequireRecord <bool>] [-DisallowFallback <bool>] [-RequireAiBotRules <bool>] [-RequireSitemap <bool>] [<CommonParameters>]
```

## DESCRIPTION
The returned object is intended to be used with New-DDDesiredState or applied to an existing configuration.

## EXAMPLES

### EXAMPLE 1
```powershell
PS> New-DDDesiredStateRobots -RequireRecord $true -RequireAiBotRules $true -RequireSitemap $true
```
