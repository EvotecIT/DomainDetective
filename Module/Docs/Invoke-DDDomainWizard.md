# Invoke-DDDomainWizard
## SYNOPSIS
Starts an interactive wizard to run domain checks.

## SYNTAX
### __AllParameterSets
```powershell
Invoke-DDDomainWizard [<CommonParameters>]
```

## DESCRIPTION
Part of the DomainDetective project.

## EXAMPLES

### EXAMPLE 1
```powershell
Invoke-DDDomainWizard
```
