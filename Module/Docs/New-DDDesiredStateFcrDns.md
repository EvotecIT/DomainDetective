# New-DDDesiredStateFcrDns
## SYNOPSIS
Creates an FCrDNS desired state policy fragment.

## SYNTAX
### __AllParameterSets
```powershell
New-DDDesiredStateFcrDns [-Enabled <Boolean>] [-RequireAtLeastOneResult <Boolean>] [-RequireAllForwardConfirmed <Boolean>] [<CommonParameters>]
```

## DESCRIPTION
The returned object is intended to be used with New-DDDesiredState or applied to an existing configuration.

## EXAMPLES

### EXAMPLE 1
```powershell
PS> New-DDDesiredStateFcrDns -RequireAllForwardConfirmed $true
```
