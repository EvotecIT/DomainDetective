# New-DDDesiredStateSoa
## SYNOPSIS
Creates an SOA desired state policy fragment.

## SYNTAX
### __AllParameterSets
```powershell
New-DDDesiredStateSoa [-Enabled <bool>] [-RequireRecord <bool>] [-RequireSerialFormat <bool>] [-MinRefresh <int>] [-MaxRefresh <int>] [-MinRetry <int>] [-MaxRetry <int>] [-MinExpire <int>] [-MaxExpire <int>] [-MinMinimum <int>] [-MaxMinimum <int>] [<CommonParameters>]
```

## DESCRIPTION
The returned object is intended to be used with New-DDDesiredState or applied to an existing configuration.

## EXAMPLES

### EXAMPLE 1
```powershell
New-DDDesiredStateSoa -Enabled 'Value'
```
