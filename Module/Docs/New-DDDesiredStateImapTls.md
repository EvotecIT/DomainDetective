# New-DDDesiredStateImapTls
## SYNOPSIS
Creates an IMAP TLS desired state policy fragment.

## SYNTAX
### __AllParameterSets
```powershell
New-DDDesiredStateImapTls [-Enabled <bool>] [-RequireAtLeastOneResult <bool>] [-RequireCertificateValid <bool>] [-RequireChainValid <bool>] [-RequireHostnameMatch <bool>] [-DisallowExpiredCertificates <bool>] [-MinCertificateDaysToExpire <int>] [-DisallowLegacyProtocols <bool>] [-MinimumGradeLevel <GradeLevel>] [<CommonParameters>]
```

## DESCRIPTION
The returned object is intended to be used with New-DDDesiredState or applied to an existing configuration.

## EXAMPLES

### EXAMPLE 1
```powershell
PS> New-DDDesiredStateImapTls -RequireCertificateValid $true -DisallowLegacyProtocols $true -MinimumGradeLevel B
```
