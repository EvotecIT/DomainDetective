# New-DDDesiredStateFlatteningService
## SYNOPSIS
Creates a flattening service desired state policy fragment.

## SYNTAX
### __AllParameterSets
```powershell
New-DDDesiredStateFlatteningService [-Enabled <bool>] [-RequireCnameRecord <bool>] [-DisallowCnameRecord <bool>] [-RequireFlatteningService <bool>] [-DisallowFlatteningService <bool>] [-AllowedTargetSuffixes <string[]>] [<CommonParameters>]
```

## DESCRIPTION
The returned object is intended to be used with New-DDDesiredState or applied to an existing configuration.

## EXAMPLES

### EXAMPLE 1
```powershell
New-DDDesiredStateFlatteningService -AllowedTargetSuffixes @('Value')
```
