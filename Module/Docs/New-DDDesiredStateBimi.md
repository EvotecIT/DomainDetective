# New-DDDesiredStateBimi
## SYNOPSIS
Creates a BIMI desired state policy fragment.

## SYNTAX
### __AllParameterSets
```powershell
New-DDDesiredStateBimi [-Enabled <bool>] [-RequireRecord <bool>] [-RequireIndicator <bool>] [-RequireValidLocation <bool>] [-AllowedLocationHostSuffixes <string[]>] [-RequireAuthority <bool>] [-AllowedAuthorityHostSuffixes <string[]>] [-SkipIndicatorDownload <bool>] [<CommonParameters>]
```

## DESCRIPTION
The returned object is intended to be used with New-DDDesiredState or applied to an existing configuration.

## EXAMPLES

### EXAMPLE 1
```powershell
PS> New-DDDesiredStateBimi -Enabled $true -RequireValidLocation $true -AllowedLocationHostSuffixes cdn.vendor.example -SkipIndicatorDownload $true
```
