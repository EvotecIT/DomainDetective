# New-DDDesiredStateWildcardDns
## SYNOPSIS
Creates a wildcard DNS desired state policy fragment.

## SYNTAX
### __AllParameterSets
```powershell
New-DDDesiredStateWildcardDns [-Enabled <bool>] [-ExpectedCatchAll <bool>] [<CommonParameters>]
```

## DESCRIPTION
The returned object is intended to be used with New-DDDesiredState or applied to an existing configuration.

## EXAMPLES

### EXAMPLE 1
```powershell
New-DDDesiredStateWildcardDns -Enabled 'Value'
```
