# Test-DDSitemap
## SYNOPSIS
Validates sitemap XML and sitemap-listed URLs.

## SYNTAX
### __AllParameterSets
```powershell
Test-DDSitemap [-Subject] <string[]> [-TimeoutSeconds <int>] [-MaxSitemapDocuments <int>] [-MaxEntries <int>] [-MaxUrlProbes <int>] [-MaxRedirects <int>] [-NoUrlProbe] [-NoCanonicalCheck] [-NoHttpFallback] [-UserAgent <string>] [-ExportFormat <ReportFormat[]>] [-ExportPath <string>] [-OpenInBrowser] [-ExportArtifacts] [-ArtifactsDirectory <string>] [-DisableParallel] [-ThrottleLimit <int>] [-MaxParallelism <int>] [-DnsParallelism <int>] [-DnsEndpoints <DnsEndpoint[]>] [-MultiResolverStrategy <MultiResolverStrategy>] [-MultiResolverMaxParallelism <int>] [<CommonParameters>]
```

## DESCRIPTION
Checks sitemap discovery, XML shape, urlset and sitemapindex entries, duplicate locations, redirects, redirect loops, HTTP errors, noindex, and canonical mismatches.

## EXAMPLES

### EXAMPLE 1
```powershell
PS> Test-DDSitemap -Subject evotec.pl
```


### EXAMPLE 2
```powershell
PS> Test-DDSitemap -Subject https://example.com/sitemap.xml -MaxUrlProbes 1000
```
