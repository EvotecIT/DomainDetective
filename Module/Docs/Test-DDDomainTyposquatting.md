# Test-DDDomainTyposquatting
## SYNOPSIS
Generates and evaluates typosquatting candidates for a domain.

## SYNTAX
### ServerName (Default)
```powershell
Test-DDDomainTyposquatting [-DomainName] <string[]> [[-DnsEndpoint] <DnsEndpoint>] [-ExportFormat <ReportFormat[]>] [-ExportPath <string>] [-OpenInBrowser] [-ExportArtifacts] [-ArtifactsDirectory <string>] [-DisableParallel] [-ThrottleLimit <int>] [-MaxParallelism <int>] [-DnsParallelism <int>] [-DnsEndpoints <DnsEndpoint[]>] [-MultiResolverStrategy <MultiResolverStrategy>] [-MultiResolverMaxParallelism <int>] [-BrandKeyword <string[]>] [-DictionaryWord <string[]>] [-AlternativeTld <string[]>] [-LevenshteinThreshold <int>] [-EnableVisualSimilarity] [-EnableBrowserScreenshot] [-VisualMaxCandidates <int>] [-VisualMaxAssetsPerPage <int>] [-EnableSmtpBanner] [-EnableSmtpRecipientAcceptance] [<CommonParameters>]
```

## DESCRIPTION
Part of the DomainDetective project.

## EXAMPLES

### EXAMPLE 1
```powershell
Test-DDDomainTyposquatting -DomainName example.com -BrandKeyword paypal
```
