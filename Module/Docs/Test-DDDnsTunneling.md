# Test-DDDnsTunneling
## SYNOPSIS
Analyzes DNS logs for tunneling patterns.

## SYNTAX
### File (Default)
```powershell
Test-DDDnsTunneling [-DomainName] <string[]> [-Path] <string> [-ExportFormat <ReportFormat[]>] [-ExportPath <string>] [-OpenInBrowser] [-ExportArtifacts] [-ArtifactsDirectory <string>] [-DisableParallel] [-ThrottleLimit <int>] [-MaxParallelism <int>] [-DnsParallelism <int>] [-DnsEndpoints <DnsEndpoint[]>] [-MultiResolverStrategy <MultiResolverStrategy>] [-MultiResolverMaxParallelism <int>] [<CommonParameters>]
```

## DESCRIPTION
Outputs a view object with full raw analysis attached at Raw.

## EXAMPLES

### EXAMPLE 1
```powershell
Test-DDDnsTunneling -DomainName example.com -Path ./dns.log
```
