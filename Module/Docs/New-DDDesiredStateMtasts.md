# New-DDDesiredStateMtasts
## SYNOPSIS
Creates an MTA-STS desired state policy fragment.

## SYNTAX
### __AllParameterSets
```powershell
New-DDDesiredStateMtasts [-Enabled <bool>] [-RequireRecord <bool>] [-RequireDnsRecordValid <bool>] [-RequirePolicyPresent <bool>] [-RequirePolicyValid <bool>] [-DisallowDuplicateFields <bool>] [-RequireEnforce <bool>] [-MinMaxAge <int>] [-RequireMxAligned <bool>] [<CommonParameters>]
```

## DESCRIPTION
The returned object is intended to be used with New-DDDesiredState or applied to an existing configuration.

## EXAMPLES

### EXAMPLE 1
```powershell
PS> New-DDDesiredStateMtasts -Enabled $true -RequireRecord $true -RequireEnforce $true -MinMaxAge 86400
```
