# Get-DDDomainWhois
## SYNOPSIS
Retrieves WHOIS information for the specified domain.

## SYNTAX
### ServerName (Default)
```powershell
Get-DDDomainWhois [-DomainName] <string[]> [[-DnsEndpoint] <DnsEndpoint>] [-DisableParallel] [-ThrottleLimit <int>] [-MaxParallelism <int>] [-DnsParallelism <int>] [-DnsEndpoints <DnsEndpoint[]>] [-MultiResolverStrategy <MultiResolverStrategy>] [-MultiResolverMaxParallelism <int>] [-SnapshotPath <string>] [-Diff] [-FollowReferral] [-MaxReferralDepth <int>] [<CommonParameters>]
```

## DESCRIPTION
Part of the DomainDetective project.

## EXAMPLES

### EXAMPLE 1
```powershell
Get-DDDomainWhois -DomainName example.com
```
