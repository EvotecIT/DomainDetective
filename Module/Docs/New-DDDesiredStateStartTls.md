# New-DDDesiredStateStartTls
## SYNOPSIS
Creates a STARTTLS desired state policy fragment.

## SYNTAX
### __AllParameterSets
```powershell
New-DDDesiredStateStartTls [-Enabled <Boolean>] [-RequireAtLeastOneResult <Boolean>] [-RequireAnyServerSupported <Boolean>] [-RequireAllServersSupported <Boolean>] [-DisallowDowngradeDetected <Boolean>] [<CommonParameters>]
```

## DESCRIPTION
The returned object is intended to be used with New-DDDesiredState or applied to an existing configuration.

## EXAMPLES

### EXAMPLE 1
```powershell
PS> New-DDDesiredStateStartTls -RequireAllServersSupported $true -DisallowDowngradeDetected $true
```
