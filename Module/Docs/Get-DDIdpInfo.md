# Get-DDIdpInfo
## SYNOPSIS
Retrieves identity provider (IdP) information for the specified domain.

## SYNTAX
### ByName (Default)
```powershell
Get-DDIdpInfo [-DomainName] <string[]> [-DisableParallel] [-ThrottleLimit <Int32>] [-MaxParallelism <Int32>] [-DnsParallelism <Int32>] [-DnsEndpoints <DnsEndpoint[]>] [-MultiResolverStrategy <MultiResolverStrategy>] [-MultiResolverMaxParallelism <Int32>] [<CommonParameters>]
```

## DESCRIPTION
Performs OIDC discovery and GetUserRealm calls to expose tenant hints.

## EXAMPLES

### EXAMPLE 1
```powershell
Get-DDIdpInfo -DomainName example.com
```
