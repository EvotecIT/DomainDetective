## Privacy First

DomainDetective is designed with privacy as a core principle.

### Online Tools

When you use the online tools at `/tools/`:

- **All analysis runs in your browser** using WebAssembly (Blazor WASM)
- DNS queries are sent via DNS-over-HTTPS to Cloudflare (1.1.1.1)
- **No data is stored on our servers** — we don't have a backend
- **No analytics or tracking** is used on the tools pages
- Results exist only in your browser session and are not persisted

### Static Website

The documentation and marketing pages are static HTML served via GitHub Pages. No cookies or tracking scripts are used.

### Third-Party Services

- **Cloudflare DNS-over-HTTPS**: DNS queries from the browser tools are resolved via Cloudflare's DoH endpoint
- **Google Fonts**: Font files are loaded from Google Fonts CDN
- **GitHub Pages**: The site is hosted on GitHub Pages

### Contact

For privacy questions, open an issue on [GitHub](https://github.com/EvotecIT/DomainDetective/issues).
