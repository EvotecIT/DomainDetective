DnsClientX {{ x.version }} · the DNS engine inside DomainDetective

Every DNS transport. One .NET client.

DnsClientX is an async DNS library and PowerShell module for UDP, TCP, DoT, DoH, DoH3 and DoQ, with typed records, local DNSSEC validation, zone transfers, updates and service discovery. The core has no dependencies and runs from .NET Framework 4.7.2 to .NET 10.

>dotnet add package DnsClientX
PS>Install-Module DnsClientX

Built-in resolvers

Pick a provider,
or bring your own.

Named profiles cover the major public resolvers and their filtering, wire-format and QUIC variants. Anything else is one endpoint string away, including DNS stamps, private resolvers and the root servers.

  -ResolverEndpoint 'udp@1.1.1.1:53','doh@https://dns.google/dns-query' `
