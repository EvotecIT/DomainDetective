The DNS engine
underneath it all.

Every DomainDetective check asks DNS through DnsClientX, our open-source DNS client for .NET and PowerShell. Use it on its own when you need DNS without the analysis: any transport, typed records, local DNSSEC validation, zone transfers and service discovery, with no dependencies in the core.

using DnsClientX;
