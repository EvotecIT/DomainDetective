Frequently Asked Questions

What is DomainDetective?

DomainDetective is a domain analysis toolkit with 115+ checks across DNS, email authentication, TLS, HTTP security, threat intelligence, and subdomain discovery. It is available as a C# library, PowerShell module, CLI tool, and browser-based toolkit.

Is my data safe?

Yes. DNS checks run browser-side via DNS-over-HTTPS, and advanced HTTP/TLS checks use the hosted analysis API only when the browser cannot inspect them directly. DomainDetective does not store your query data or analysis output.

What protocols are supported?

Supported checks include SPF, DKIM, DMARC, MX, MTA-STS, TLS-RPT, BIMI, DNSSEC, TLS certificates, DANE, CAA, HTTP security headers, security.txt, RDAP / WHOIS, DNSBL, dangling CNAME detection, and Certificate Transparency discovery.

Can I use it in my own application?

Absolutely. You can add it to .NET applications with dotnet add package DomainDetective, use the PowerShell module, or automate it from the CLI.

Is it really free?

Yes. DomainDetective is MIT licensed and open source, so you can use it in personal or commercial environments without paid tiers or hidden limits.
