Frequently Asked Questions

What is DomainDetective?

DomainDetective is a comprehensive domain analysis toolkit that performs 115+ protocol checks including SPF, DKIM, DMARC, DNSSEC, TLS certificate validation, HTTP security headers, DNSBL lookups, and more. It is available as a C# library, PowerShell module, CLI tool, and online web application.

Is my data safe?

Yes. All analysis runs entirely client-side in your browser using DNS-over-HTTPS. No domain data is stored, transmitted to our servers, or shared with third parties. You can verify this by inspecting the open-source code on GitHub.

What protocols are supported?

DomainDetective supports SPF, DKIM, DMARC, MX, MTA-STS, TLS-RPT, BIMI, DNSSEC, DNS propagation, TLS certificate checks, DANE, CAA records, HTTP security headers, Security.txt, RDAP/WHOIS, DNSBL blacklist checks, dangling CNAME detection, and Certificate Transparency subdomain discovery.

Can I use it in my own application?

Absolutely. DomainDetective is available as a NuGet package that you can add to any .NET project. It targets .NET 8+, .NET Standard 2.0, and .NET Framework 4.7.2, making it compatible with a wide range of applications. Install it with dotnet add package DomainDetective.

Is it really free?

Yes. DomainDetective is fully open source under the MIT license. You can use it for personal, commercial, or educational purposes without any restrictions. There are no paid tiers, usage limits, or hidden costs.
